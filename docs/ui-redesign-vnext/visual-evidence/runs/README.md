# Historical visual runs

These runs are historical evidence, not acceptance of the current source.
The complete original tree (1,508 files) is preserved in the
[verified archive](../../../history/visual-evidence-2026-10-18.tar.gz).
The [retention manifest](../../../history/visual-evidence-2026-10-18-manifest.json)
records each original path, size, SHA-256 and retained/archive action.
All archive members were checked against original bytes before 1,492 originals
were moved out of this directory. Sixteen directly cited files/acceptance indexes
remain at their original paths. No unique failed-run or screenshot evidence was
discarded. Nested attachment links in historical reports require restoration.

From the repository root, restore the original paths when inspecting a run:

```bash
tar -xzf docs/history/visual-evidence-2026-10-18.tar.gz -C .
```

The archive contains only the listed historical `docs/.../runs/...` paths.
Do not count restored historical screenshots as current visual acceptance.
